# RetailPulse — Retail Sales Performance Analytics

RetailPulse is an end-to-end retail analytics project that transforms raw Superstore sales data into cleaned datasets, SQL insights, statistical analysis, and Tableau-ready outputs for business decision-making.

## Business Problem

Retail teams often have sales data but lack a clear view of which regions, products, customers, and discount strategies are actually driving profitable growth. This project solves that problem by building a repeatable analytics workflow that cleans retail transaction data, tests key business hypotheses, and prepares executive-ready outputs for dashboarding and decision support.

## Setup Instructions

### 1. Download the dataset

Download the Superstore dataset from Kaggle and place `Sample - Superstore.csv` in the project root:

- Kaggle dataset: `Sample - Superstore.csv`
- Expected location: `/Users/vijai/Documents/New project/Sample - Superstore.csv`

### 2. Install requirements

Create and activate a virtual environment if you want an isolated setup, then install the required libraries:

```bash
pip install pandas numpy scipy seaborn matplotlib
```

SQLite is included with standard Python installations, so no separate install is usually required.

### 3. Run the scripts in order

Run the project pipeline in this sequence:

```bash
python3 data_cleaning.py
python3 run_sql.py
python3 statistical_analysis.py
python3 tableau_prep.py
```

What each script does:

1. `data_cleaning.py`
   Cleans the raw CSV, engineers analysis features, and exports `superstore_clean.csv`.
2. `run_sql.py`
   Loads the cleaned dataset into SQLite, executes the SQL analysis queries, prints results, and exports CSV outputs to `sql_results/`.
3. `statistical_analysis.py`
   Runs correlation analysis, ANOVA, t-tests, segment profitability analysis, and time series trend analysis. It also saves visualization images.
4. `tableau_prep.py`
   Creates Tableau-optimized summary files inside `tableau_data/`.

## Workflow Summary

This project follows a practical retail analytics pipeline:

1. Ingest raw transactional data from Kaggle.
2. Clean and standardize date, sales, profit, and discount fields.
3. Enrich the dataset with time-based and profitability features.
4. Run SQL-based business analysis for repeatable reporting.
5. Perform statistical testing to validate business assumptions.
6. Prepare lightweight, visualization-ready extracts for Tableau Public.

## Outputs

After running the full workflow, the project will produce:

- A cleaned master dataset for downstream analysis
- SQL result tables exported as CSV files
- Statistical visualizations saved as PNG files
- Tableau-ready summary files for dashboard building
